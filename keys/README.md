# Deneme imza anahtarı

`deneme-anahtari.p12` (şifre: `hafizlik-deneme`, takma ad: `hafizlik`) deneme APK'larını imzalar. Gizli değildir.
Her deneme sürümü aynı anahtarla imzalandığı için yeni sürüm eskisinin üstüne kurulur, ilerleme silinmez.

Google Play'e yüklenecek paket bu anahtarla değil, ayrı tutulan gizli bir yükleme anahtarıyla imzalanacak. O anahtar bu depoya konmaz.
